# 14-Coding-Standards: Clean Code & Architecture Rules

## Engineering Mandates
- **No Duplicated Code**: Extract reusable hooks, utilities, and components.
- **No Magic Numbers**: Use named constants and configuration enums.
- **Strict TypeScript**: No `any` types allowed without explicit justification.
- **No Inline SQL / CSS**: Use Drizzle ORM queries and Tailwind utility classes exclusively.
- **Zero Temporary Fixes**: Build permanent architecture from day one.
