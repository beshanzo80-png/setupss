# 11-UI-Standards: Neo-Brutalist Design Tokens & Typography

## Design System Tokens
- **Background**: `#f4f6f8` (Sophisticated cool neutral).
- **Primary Dark**: `#1a1a1a` (Deep obsidian).
- **Accent Yellow**: `#ffd93d` (Vibrant electric yellow).
- **Accent Coral**: `#ff6b6b` (Vibrant coral red).
- **Borders & Shadows**: 2px to 4px solid `#1a1a1a` with hard offset shadows (`4px 4px 0px 0px rgba(26,26,26,1)`).
- **Typography**: Plus Jakarta Sans for UI body, Display font headings with strict tracking and line-height constraints.
