# 16-Performance: Core Web Vitals & Optimization

## Performance Objectives
- **First Contentful Paint (FCP)**: < 1.0s via edge caching and programmatic SEO prerendering.
- **Cumulative Layout Shift (CLS)**: Exactly 0.0 by enforcing explicit dimensions on media and cards.
- **Bundle Optimization**: Code splitting and tree shaking via Vite and esbuild.
